## 문제 1
[자바 객체지향 프로그래밍] 자바의 접근 제어자(Access Modifier) 중 동일한 패키지 내의 클래스뿐만 아니라, 다른 패키지에 속하더라도 해당 클래스를 상속받은 자식 클래스에서 접근을 허용하는 제어자는 무엇인가?
1) public
2) protected
3) default
4) private

정답: 2
해설: protected 제어자는 동일 패키지 내부 및 다른 패키지더라도 해당 클래스를 상속받은 자식 클래스에서의 접근을 허용합니다.

## 문제 2
[자바 객체지향 프로그래밍] 다음 Calculator 클래스 코드를 바탕으로 작성된 아래 코드에서 컴파일 에러가 발생하는 행은 어디인가?
```java
public class Calculator {
  int instanceVal = 10;
  static int staticVal = 20;

  public static void staticMethod() {
    System.out.println(staticVal); // (A)
    System.out.println(instanceVal); // (B)
  }

  public void instanceMethod() {
    System.out.println(staticVal); // (C)
    System.out.println(instanceVal); // (D)
  }
}
```
1) (A)
2) (B)
3) (C)
4) (D)

정답: 2
해설: static 메서드는 객체가 생성되기 전 클래스 로딩 시점에 메모리에 배치되므로, 객체가 생성되어야만 힙 영역에 존재하는 인스턴스 변수(instanceVal)에 직접 접근할 수 없습니다.
https://github.com/BEBC-25/java-yong/blob/main/docs/02.java_oop.md#1110-정적static-멤버

## 문제 3
[자바 객체지향 프로그래밍] 다형성이 성립하기 위한 조건이 아닌 것은 무엇인가?
1) 두 클래스 간에 부모와 자식의 상속 관계가 성립해야 한다.
2) 부모 클래스의 메서드가 자식 클래스에서 오버라이딩(재정의)되어 있어야 한다.
3) 자식 클래스 타입의 참조 변수로 부모 클래스의 인스턴스를 가리켜 참조해야 한다.
4) 부모 클래스 타입의 참조 변수로 자식 클래스의 인스턴스를 가리켜 참조해야 한다.

정답: 3
해설: 다형성을 구현하려면 상위(부모) 클래스 타입의 참조 변수로 하위(자식) 클래스의 인스턴스를 가리켜야 합니다. 자식 타입의 참조 변수로 부모 객체를 가리켜 대입하는 것은 허용되지 않습니다.

## 문제 4
[자바 객체지향 프로그래밍] 다음 Animal과 Dog 클래스의 상속 관계를 바탕으로 구성한 자바 코드 중 실행(Runtime) 시점에 ClassCastException이 발생하는 행은 무엇인가?
```java
class Animal {}
class Dog extends Animal {}

Animal a1 = new Animal();
Animal a2 = new Dog();
```
1) Dog d1 = (Dog) a1;
2) Dog d2 = (Dog) a2;
3) Animal a3 = new Dog();
4) Object obj = a2;

정답: 1
해설: a1은 부모 타입인 Animal 객체를 가리키고 있으므로, 실제 자식 객체가 아닌 인스턴스를 강제 형변환(Downcasting)하려고 하면 런타임에 ClassCastException이 발생합니다.
https://github.com/BEBC-25/java-yong/blob/main/docs/02.java_oop.md#131-다형성

## 문제 5
[데이터베이스 기초] 데이터베이스 SQL의 분류 중 데이터 정의어(DDL)에 해당하지 않는 명령어는 무엇인가?
1) CREATE
2) ALTER
3) DROP
4) INSERT

정답: 4
해설: INSERT는 테이블에 데이터를 삽입하는 데이터 조작어(DML)에 해당합니다. CREATE, ALTER, DROP은 테이블이나 데이터베이스 구조를 다루는 DDL입니다.

## 문제 6
[데이터베이스 기초] 테이블의 기본 키(Primary Key)와 외래 키(Foreign Key)에 대한 설명으로 올바르지 않은 것은?
1) 기본 키는 테이블에서 각 행을 식별할 수 있는 유일한 값을 가져야 한다.
2) 기본 키는 중복된 값을 가질 수 없지만, NULL 값은 가질 수 있다.
3) 외래 키는 다른 테이블의 기본 키를 참조하여 테이블 간의 관계를 형성한다.
4) 1대N 관계 설계 시, N에 해당하는 테이블에 외래 키를 배치하여 1에 해당하는 테이블의 기본 키를 참조하게 한다.

정답: 2
해설: 기본 키(PK)는 식별을 위해 존재하므로 NULL 값을 가질 수 없으며 중복된 값 또한 허용하지 않습니다.
https://github.com/BEBC-25/java-yong/blob/main/docs/03.database-1.md#122-기본-키pk와-외래-키fk

## 문제 7
[데이터베이스 기초] 다중 테이블 조인(JOIN) 중 기준이 되는 테이블의 모든 행을 유지하며, 다른 테이블에 매칭되는 행이 없으면 해당 컬럼을 NULL로 채워 결과를 반환하는 조인은 무엇인가?
1) INNER JOIN
2) LEFT/RIGHT OUTER JOIN
3) SELF JOIN
4) CROSS JOIN

정답: 2
해설: OUTER JOIN(LEFT 또는 RIGHT)은 조인 조건에 일치하지 않더라도 기준 테이블의 행 데이터를 모두 살리고 상대 테이블의 매칭 데이터를 NULL로 표시합니다.

## 문제 8
[데이터베이스 심화 및 자바 연동] JDBC 프로그램에서 사용하는 주요 인터페이스와 그 역할에 대한 설명으로 가장 올바르지 않은 것은?
1) Connection: 데이터베이스와의 연결을 수립하고 트랜잭션을 관리한다.
2) Statement: SQL 쿼리를 데이터베이스로 보내 실행한다.
3) PreparedStatement: SQL 문을 미리 컴파일하여 보안성과 실행 속도를 높인다.
4) ResultSet: 데이터베이스 로그인 계정 정보(아이디, 패스워드)를 저장하고 관리한다.

정답: 4
해설: ResultSet은 SQL SELECT 쿼리 실행 결과로 반환된 데이터를 보관하고 행 단위로 순회하여 값을 가져오는 인터페이스입니다. DB 계정 정보를 관리하지 않습니다.
https://github.com/BEBC-25/java-yong/blob/main/docs/04.database-2.md#715-jdbc-핵심-인터페이스-및-클래스-역할

## 문제 9
[자바 프로그래밍 심화] 자바의 예외(Exception) 계층 구조 중 컴파일 시점에 예외 처리를 강제하는 Checked Exception에 해당하는 예외 클래스는 무엇인가?
1) NullPointerException
2) ArithmeticException
3) IndexOutOfBoundsException
4) IOException

정답: 4
해설: IOException은 RuntimeException 계열을 상속받지 않은 Checked Exception에 해당하므로 컴파일러가 반드시 예외 처리를 하도록 강제합니다. 반면 1, 2, 3번은 모두 RuntimeException을 상속받은 Unchecked Exception입니다.
https://github.com/BEBC-25/java-yong/blob/main/docs/05.java_advanced.md#12-예외-클래스의-계층-구조

## 문제 10
[자바 프로그래밍 심화] 자바의 컬렉션 프레임워크(Collection Framework)에 속한 핵심 인터페이스들의 특징을 설명한 내용으로 올바르지 않은 것은?
1) List는 데이터의 저장 순서를 유지하며 데이터의 중복 저장을 허용한다.
2) Set은 데이터의 저장 순서를 보장하지 않으며 데이터의 중복 저장을 허용하지 않는다.
3) Map은 Key와 Value의 쌍으로 데이터를 관리하며 Key는 중복될 수 없다.
4) Collection 인터페이스는 List, Set, Map의 공통 기능을 추출하여 정의한 최상위 인터페이스이다.

정답: 4
해설: Collection 인터페이스는 List, Set, Queue의 최상위 인터페이스이지만, Key-Value 구조인 Map 인터페이스는 이와 별개의 계층 구조로 설계되어 있습니다.
https://github.com/BEBC-25/java-yong/blob/main/docs/05.java_advanced.md#22-컬렉션-프레임워크
